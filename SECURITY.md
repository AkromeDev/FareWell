# Security

## Reporting a vulnerability

If you find a security problem in farewell.salon or in this repository, please
write to **info@farewell.salon** with a short description, the address or file
concerned, and the steps to reproduce it. German or English are both fine.

Please do not open a public GitHub issue for a security problem, and do not
access, change or delete data that is not yours while testing.

We confirm receipt within a few working days and tell you what we do about it.

The same contact is published at https://farewell.salon/.well-known/security.txt.
